Switches between sibling views in place.

Match each `TabsTrigger` `value` to its `TabsContent` `value`. Use for peer views, never as a wizard. Variants: `default` (filled track) and `line`.

## Parts

Composed inside `<Tabs>`, each importable from `window.NabaPresence.*`:

- `TabsContent`
- `TabsList`
- `TabsTrigger`
