Persistent horizontal application menu.

Use for desktop-style app chrome with multiple top-level menus. For a single trigger use `DropdownMenu`.

## Parts

Composed inside `<Menubar>`, each importable from `window.NabaReview.*`:

- `MenubarCheckboxItem`
- `MenubarContent`
- `MenubarGroup`
- `MenubarItem`
- `MenubarLabel`
- `MenubarMenu`
- `MenubarPortal`
- `MenubarRadioGroup`
- `MenubarRadioItem`
- `MenubarSeparator`
- `MenubarShortcut`
- `MenubarSub`
- `MenubarSubContent`
- `MenubarSubTrigger`
- `MenubarTrigger`
