The primary action control, rendered on Base UI's button primitive.

Use `variant="default"` for the single most important action per view and `outline`/`ghost` for secondary ones. `destructive` renders as red text on a tint, not a solid red fill — that is deliberate. Sizes are `xs`|`sm`|`default`|`lg` plus `icon`, `icon-xs`, `icon-sm`, `icon-lg` for square icon-only buttons.
