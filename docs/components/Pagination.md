Page-by-page navigation for long lists.

Compose `PaginationPrevious`, `PaginationLink` items, `PaginationEllipsis`, and `PaginationNext`. Mark the active page with `isActive`.

## Parts

Composed inside `<Pagination>`, each importable from `window.NabaReview.*`:

- `PaginationContent`
- `PaginationEllipsis`
- `PaginationItem`
- `PaginationLink`
- `PaginationNext`
- `PaginationPrevious`
