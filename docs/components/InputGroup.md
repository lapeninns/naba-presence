An input with attached addons — icons, buttons, or text.

Put the control in `InputGroupInput`/`InputGroupTextarea` and affixes in `InputGroupAddon`. Use `data-align` on the addon (`inline-start`, `inline-end`, `block-start`, `block-end`) to position it. The group owns the focus ring, so do not style the inner input.

## Parts

Composed inside `<InputGroup>`, each importable from `window.NabaPresence.*`:

- `InputGroupAddon`
- `InputGroupButton`
- `InputGroupInput`
- `InputGroupText`
- `InputGroupTextarea`
