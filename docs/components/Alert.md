Inline message about the current view.

Compose `AlertTitle` and `AlertDescription`, plus `AlertAction` for a recovery control. Use `destructive` for errors. For anything needing acknowledgement use `AlertDialog`; for transient confirmation use `Toast`.

## Parts

Composed inside `<Alert>`, each importable from `window.NabaReview.*`:

- `AlertAction`
- `AlertDescription`
- `AlertTitle`
