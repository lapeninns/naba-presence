Ancestor trail for the current page.

Mark the current page with `BreadcrumbPage` (not a link) and use `BreadcrumbEllipsis` to collapse long trails.

## Parts

Composed inside `<Breadcrumb>`, each importable from `window.NabaPresence.*`:

- `BreadcrumbEllipsis`
- `BreadcrumbItem`
- `BreadcrumbLink`
- `BreadcrumbList`
- `BreadcrumbPage`
- `BreadcrumbSeparator`
