Panel that slides in and supports swipe dismissal.

Best for mobile-first flows. Same header/footer composition as `Dialog`; `DrawerSwipeHandle` renders the grab affordance.

## Parts

Composed inside `<Drawer>`, each importable from `window.NabaPresence.*`:

- `DrawerClose`
- `DrawerContent`
- `DrawerDescription`
- `DrawerFooter`
- `DrawerHeader`
- `DrawerOverlay`
- `DrawerPortal`
- `DrawerSwipeHandle`
- `DrawerTitle`
- `DrawerTrigger`
