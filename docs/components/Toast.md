Transient notification.

Requires `ToastProvider` and a `ToastViewport` mounted once near the app root (or the prebuilt `Toaster`). Use for confirmation of a completed action; never for errors the user must act on.

## Parts

Composed inside `<Toast>`, each importable from `window.NabaPresence.*`:

- `ToastAction`
- `ToastClose`
- `ToastContent`
- `ToastDescription`
- `ToastPortal`
- `ToastProvider`
- `ToastTitle`
- `ToastViewport`
- `Toaster`
