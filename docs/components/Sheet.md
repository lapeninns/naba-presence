Panel anchored to a screen edge.

Set `side` to `top`|`right`|`bottom`|`left`. Use for filters, detail panes, and mobile navigation. Prefer `Drawer` when swipe-to-dismiss matters.

## Parts

Composed inside `<Sheet>`, each importable from `window.NabaReview.*`:

- `SheetClose`
- `SheetContent`
- `SheetDescription`
- `SheetFooter`
- `SheetHeader`
- `SheetTitle`
- `SheetTrigger`
