Joins adjacent buttons, inputs, or select triggers into one segmented control.

Wrap two or more controls to merge their borders and radii. Accepts `Button`, `Input`, `InputGroup`, and `SelectTrigger` children; use `ButtonGroupSeparator` between segments and `ButtonGroupText` for inline non-interactive labels.

## Parts

Composed inside `<ButtonGroup>`, each importable from `window.NabaPresence.*`:

- `ButtonGroupSeparator`
- `ButtonGroupText`
