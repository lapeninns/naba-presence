A generic list row: media, content, and actions.

Use for settings rows, search results, and file lists — anywhere a full `Card` is too heavy. Compose `ItemMedia`, `ItemContent` (with `ItemTitle`/`ItemDescription`), and `ItemActions`. `ItemGroup` renders as a semantic list.

## Parts

Composed inside `<Item>`, each importable from `window.NabaPresence.*`:

- `ItemActions`
- `ItemContent`
- `ItemDescription`
- `ItemFooter`
- `ItemGroup`
- `ItemHeader`
- `ItemMedia`
- `ItemSeparator`
- `ItemTitle`
