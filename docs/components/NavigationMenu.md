Site navigation with rich dropdown panels.

Use for marketing or multi-section navigation where items need descriptions. For in-app chrome prefer `Sidebar` or `Menubar`.

## Parts

Composed inside `<NavigationMenu>`, each importable from `window.NabaPresence.*`:

- `NavigationMenuContent`
- `NavigationMenuIndicator`
- `NavigationMenuItem`
- `NavigationMenuLink`
- `NavigationMenuList`
- `NavigationMenuPositioner`
- `NavigationMenuTrigger`
