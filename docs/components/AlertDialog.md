Modal that interrupts to confirm a consequential action.

Use this — never `Dialog` — for destructive confirmation. `AlertDialogAction` performs it and `AlertDialogCancel` dismisses. State the consequence in `AlertDialogDescription`.

## Parts

Composed inside `<AlertDialog>`, each importable from `window.NabaPresence.*`:

- `AlertDialogAction`
- `AlertDialogCancel`
- `AlertDialogContent`
- `AlertDialogDescription`
- `AlertDialogFooter`
- `AlertDialogHeader`
- `AlertDialogMedia`
- `AlertDialogOverlay`
- `AlertDialogPortal`
- `AlertDialogTitle`
- `AlertDialogTrigger`
