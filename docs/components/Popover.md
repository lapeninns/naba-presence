Floating panel anchored to a trigger.

Use for pickers and secondary controls. Pass the trigger via `render`. For a menu of actions use `DropdownMenu`; for a passive hint use `Tooltip`.

## Parts

Composed inside `<Popover>`, each importable from `window.NabaReview.*`:

- `PopoverContent`
- `PopoverDescription`
- `PopoverHeader`
- `PopoverTitle`
- `PopoverTrigger`
