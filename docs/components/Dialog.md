Modal for focused tasks.

Compose `DialogHeader` (with `DialogTitle`, `DialogDescription`), body content, and `DialogFooter`. Pass the opener via `DialogTrigger`'s `render` prop. For destructive confirmation use `AlertDialog` instead.

## Parts

Composed inside `<Dialog>`, each importable from `window.NabaPresence.*`:

- `DialogClose`
- `DialogContent`
- `DialogDescription`
- `DialogFooter`
- `DialogHeader`
- `DialogOverlay`
- `DialogPortal`
- `DialogTitle`
- `DialogTrigger`
