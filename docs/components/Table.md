Semantic data table.

Compose `TableHeader`/`TableBody` with `TableRow`, `TableHead`, and `TableCell`. Right-align numeric columns and set numbers in `font-mono` so digits line up. Tables are wide — give them their own horizontal scroll container rather than letting the page scroll.

## Parts

Composed inside `<Table>`, each importable from `window.NabaReview.*`:

- `TableBody`
- `TableCaption`
- `TableCell`
- `TableFooter`
- `TableHead`
- `TableHeader`
- `TableRow`
