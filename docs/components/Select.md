Dropdown selection built on Base UI's select.

Pass `items` to the root so `SelectValue` renders the option label instead of the raw value — a very common omission. The popover opens as a dark translucent surface in both themes by design. For long lists prefer `Combobox`.

## Parts

Composed inside `<Select>`, each importable from `window.NabaPresence.*`:

- `SelectContent`
- `SelectGroup`
- `SelectItem`
- `SelectLabel`
- `SelectScrollDownButton`
- `SelectScrollUpButton`
- `SelectSeparator`
- `SelectTrigger`
- `SelectValue`
