Typeahead selection with filtering, single or multi.

Use when the option list is long enough to need search. `ComboboxChips` plus `ComboboxChip` renders multi-select as removable chips.

## Parts

Composed inside `<Combobox>`, each importable from `window.NabaPresence.*`:

- `ComboboxChip`
- `ComboboxChips`
- `ComboboxChipsInput`
- `ComboboxCollection`
- `ComboboxContent`
- `ComboboxEmpty`
- `ComboboxGroup`
- `ComboboxInput`
- `ComboboxItem`
- `ComboboxLabel`
- `ComboboxList`
- `ComboboxSeparator`
- `ComboboxTrigger`
- `ComboboxValue`
