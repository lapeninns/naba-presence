Command palette with fuzzy search.

Use `CommandDialog` for the ⌘K surface. Compose `CommandInput`, `CommandList`, `CommandGroup`, `CommandItem`, and `CommandEmpty` — always provide the empty state.

## Parts

Composed inside `<Command>`, each importable from `window.NabaPresence.*`:

- `CommandDialog`
- `CommandEmpty`
- `CommandGroup`
- `CommandInput`
- `CommandItem`
- `CommandList`
- `CommandSeparator`
- `CommandShortcut`
